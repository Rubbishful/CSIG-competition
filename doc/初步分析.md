# HYPIR 项目初步分析

> 创建日期：2025-08-19（会话记录）
> 目的：综合项目调研、数据统计与退化分析实验，为后续合成数据、训练与评估提供依据。
> 状态：分析阶段，尚未实施训练。

---

## 1. 项目概述

- **项目**：HYPIR（Harnessing Diffusion-Yielded Score Priors for Image Restoration），基于 Stable Diffusion 2.1 的扩散先验图像恢复模型，开源版本为 HYPIR-SD2。
- **训练方式**：`train.py` + `configs/sd2_train.yaml`，对 SD2.1 UNet 做 **LoRA 微调**（`lora_rank=256`），损失为 GAN(0.5) + LPIPS(5) + L2(1)，bf16 + 梯度检查点，`max_train_steps=30000`。
- **推理**：`SD2Enhancer`（`HYPIR/enhancer/sd2.py`），`predict.py` / `app.py` / `app_openxlab.py`。
- **预训练权重**：`HYPIR_model/HYPIR_sd2.pth` —— **纯 LoRA 权重**（514 个 `lora_A/lora_B` 张量，无 EMA 键），训练器以 `strict=False` 加载，`lora_rank=256` 一致即可续训。
- **内置合成管线**：`HYPIR/dataset/realesrgan.py` 的 `RealESRGANDataset` + `batch_transform.py` 的 `RealESRGANBatchTransform` —— Real-ESRGAN 风格在线二阶退化合成（GT → LQ），无需预存数据对。
- **硬件**：本地 + 云端（均 24GB 显存，如 RTX 4090/3090 级别）。

## 3. 退化分析实验与结论

### 3.1 实验 1：验证集 PSNR 与高频能量（GT vs LQ）

方法：RGB MSE → PSNR；Sobel 梯度幅值均值作为高频能量。

| case | PSNR (dB) | 高频能量 GT→LQ | 通道均值差 | 初步判断 |
|---|---|---|---|---|
| case1 | 32.03 | 3.3 → 2.7 | [0.93, 0.16, 0.12] | 轻度 |
| case2 | 28.19 | 23.8 → 11.1 | [0.96, 0.68, 0.40] | 中度模糊 |
| case3 | 35.62 | 5.3 → 2.7 | [0.01, 0.05, 0.12] | 轻度 |
| case4 | 18.06 | 44.1 → 7.1 | **[11.33, 8.71, 12.44]** | 重度 + 疑似偏色 |
| case5 | 26.28 | 15.9 → 15.4 | [0.47, 0.80, 0.29] | 高频损失小，噪声/伪影类 |

结论：退化程度差异大（PSNR 18~36），**case4 通道均值差达 8~12，明显偏色/曝光差异**。

### 3.2 实验 2：测试集退化程度（无 GT，粗估）

前 30 张 Sobel 高频能量：min=2.3，max=59.1，mean=17.4 → 测试集退化程度参差，与验证集一致的"多类型混合"预期。

### 3.3 实验 3：平坦区噪声 + 梯度各向异性（区分度不足，弃用）

- 平坦区噪声 std 估计 0~0.4，偏低不可靠。
- 各向异性比 GT/LQ 均在 2~9，图本身纹理方向性强，无法区分运动模糊方向。
- **结论：该指纹方法对手机摄影退化不敏感，改用残差结构分析（实验 4）。**

### 3.4 实验 4：残差结构分析（关键实验）

方法：残差 r = LQ − GT；残差高频占比 = `(r−Gaussian(r,1))² / r²`（高=噪声/压缩主导，低=模糊主导）；边缘掩码取 GT 梯度前 85% 分位。

| case | 残差RMS | 高频占比 | 边缘/平坦残差 | 通道残差均值 | 主导退化 |
|---|---|---|---|---|---|
| case1 | 6.38 | 0.04 | 12.9 / 1.7 | [1.13,-0.34,-0.56] | **纯模糊**（失焦） |
| case2 | 9.93 | 0.06 | 13.8 / 4.8 | [-0.45,-0.46,-0.33] | 模糊 + 噪声 |
| case3 | 4.22 | **0.18** | 6.4 / 1.5 | [-0.51,-0.49,-0.24] | **噪声/压缩主导** |
| case4 | 31.90 | 0.08 | 31.7 / 24.3 | **[9.14, 7.85, 11.81]** | 重度 + **偏色** |
| case5 | 12.38 | 0.08 | 19.4 / 5.5 | [0.5, 0.4, -0.7] | 边缘伪影重（重采样/锐化振铃） |

**核心结论**：
1. 退化是**多种成分的混合**，且每张图主导成分不同（模糊 / 噪声 / 偏色 / 重采样伪影）。
2. 与"手机光学 + ISP + 数码变焦/超分算法噪声 + 抖动"的描述吻合：抖动→模糊、变焦超分→边缘重采样伪影、ISP→偏色与噪声。
3. 现有 `RealESRGANBatchTransform` 默认配置（高斯类模糊 + x4 下采样）**无法覆盖**：运动模糊、偏色、同尺寸重采样伪影。

## 4. 合成数据方案（问题 1）

保留二阶退化框架（在线合成、随机组合，天然适配"多类型混合"），按手机摄影场景**替换/调整成分**：

1. **模糊**：现有 6 种高斯类核 → **增加运动模糊核**（抖动），最大缺失项。
2. **resize**：语义改为"数码变焦重采样"；`stage2_scale: 4 → 1`（同尺寸恢复），`resize_prob` 调低但保留。
3. **sinc 振铃**：`sinc_prob: 0.1 → 0.3`（sinc 自带振铃，模拟超分算法伪影）。
4. **偏色扰动**：**新增** ISP 白平衡式颜色扰动（对齐 case4 通道均值差 8~12）。
5. **裁剪**：`crop_type: none → random`、`out_size: 512`（**当前配置为 none，直接训练会报错**）；大图一裁多 patch 顺带扩增。
6. **校准闭环**：合成 LQ 的指纹（残差 RMS、高频占比、平坦残差、偏色量）直方图需与验证集 10 个真实点**覆盖重叠** —— 这是"合成数据与测试集相似度"的量化定义。

## 5. 训练方案（问题 2）

- **起点（已决策）**：从 `HYPIR_sd2.pth` 继续 LoRA 微调（`lora_rank=256` 一致，`strict=False` 加载）。
- **数据**：3.3 万张，随机裁剪 512；先 500 步验证管线（显存、loss、log 图），再全量 `max_train_steps=30000`；保留原权重作对照。
- **硬件**：24GB，bf16 + 梯度检查点 + batch 6 @512px，估算可行（未实测，首步验证）。
- **验证集隔离**：赛题验证集 10 对不参与训练，仅作客观评测。
