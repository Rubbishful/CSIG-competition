OSS zip 批次模式（2026-09 更新）

背景：数据转 OSS 存储（/mnt/data 挂载，读快写慢）；预处理产物按"一个 batch 一个 zip"聚合，
小文件只写本地 staging，避免大量小文件直接写 OSS；训练读取统一走 ZipBatchStore。
zip 语义 = 数据块（默认 512 样本/zip，OSS 对象 ~308 个），训练侧样本级随机采样 + zip 句柄 LRU。

预处理（zip 批次模式 + zip 源读取，CLI 默认 zip-batch-size=512）：
  # gt 源可直接传未解压的 merged_512.zip（避免系统盘解压 62GB）
  python -m HYPIR.dataset.preprocess --gt_dir /mnt/data/merged_512.zip \
      --output_dir /mnt/data/dataset --zip-batch-size 512 --workers 8
  产物布局：
    /mnt/data/dataset/manifest.json            # 每条记录含 'zip' + zip 源下 gt_zip/gt_arc
    /mnt/data/dataset/batches/batch_XXXXX.zip  # 内含 linear_raw/{name}.npy * batch_size
    /mnt/data/dataset/motion_blur_legal_angles.json + flare_templates/512/
  要点：
    - staging（--staging-dir，默认系统临时目录）峰值 ≈ (zip_workers+2)*batch*3.2MB；
    - 批次按 manifest 打乱顺序切分，断点续跑（跳过已存在的 batch zip）；
    - --zip-batch-size 0 恢复传统松散模式（向后兼容）；gt 目录源行为不变。

训练侧统一读取：
  from HYPIR.dataset.zip_store import ZipBatchStore
  store = ZipBatchStore("<output_dir>/manifest.json")
  store.batch_zip_paths() -> 全部批次 zip；store.load_linear_raw(name) -> np.ndarray
  store.load_gt_png(name)  -> 原始 GT sRGB（zip 源模式下从 gt_zip/gt_arc 读）
  SceneDegradation(cfg, manifest, linear_raw_loader=store.load_linear_raw) 直接可用；
  gt_path 缺失时自动用 forward_isp(vc_fixed) 高保真重建（实测 PSNR 67~113 dB）。

训练数据集包装（zip=数据块语义，样本级采样 + collate）：
  from HYPIR.dataset.scene_degradation_dataset import SceneDegradationDataset, collate_samples
  ds = SceneDegradationDataset(cfg, manifest_path)     # 内部自动接 ZipBatchStore
  batch = collate_samples([ds[i] for i in indices])

场景线训练（SceneDegradationDataset -> SD2Trainer，zip 批次产物直接训练）：
  # 预处理产物就位后（manifest.json + batches/*.zip 在 /mnt/data/dataset/）
  python train.py --config configs/sd2_scene_train.yaml
  # 配置要点：dataset.target=SceneDegradationDataset（manifest_path/cfg_path/zip_manifest），
  #           batch_transform.target=SceneBatchTransform（输出 {GT,LQ,txt}，无需在线退化）
  # 说明：训练决策链为每样本确定性 RNG（(base_seed, idx) 派生），样本级可重放；
  #       zip_store/FlareTemplateBank 已支持 pickle（DataLoader 多进程 worker 安全）。

Flare2D 模板（9,500 对 1440x1440 -> 512 模板，零裁切全图 LANCZOS 下采样）：
  python tools/prepare_flare_templates.py --num-templates 512 --templates-per-zip 128 \
      --out-dir <output_dir>/flare_templates/512
  产物：batch_XXXXX.zip（内含 templates/{id:04d}.npy [512,512,4] float32）+ 统计 CSV；
  FlareTemplateBank 自动识别 zip 批次（LRU 句柄缓存），screen 混合兼容不变。

实例小批量冒烟（解压 zip 采样 -> 预处理 -> 训练读取验证 -> 可选短训；用于选 batch 大小）：

      --batch-size 64 --workers 8
